# 精修 studio.html 的介面

## Why

`studio.html` 把套框與遮罩整合進同一頁之後，又陸續長出 JAN 匯入與逐張選取下載。功能都到位了，但介面上累積了四類問題：

1. **版面被推動**——模型狀態列平常不佔位，第一次開遮罩才出現，把整個雙欄版面往下推一整條的高度。使用者當下正在點的東西會跑掉。
2. **空間分配不合理**——一鍵區是「標籤 ⟷ 大片留白 ⟷ 兩顆按鈕」的左右對峙；檔名與縮放列擠同一行互相壓縮；清單一長，右欄預覽會捲出視野，要調最下面那張得先捲回最上面。
3. **提示沒有層級**——「3 個遮罩（胸）」與「這張不會輸出」用同一種淡色小字講，警示因此讀起來跟讀數一樣。兩段常駐的編輯說明則佔掉右欄一整塊。
4. **細節不一致**——序號靠右對齊、拖曳把手比核取方塊大一圈、性質相同的兩顆按鈕兩種樣式、清空不清 JAN 欄位。

## What Changes

- 一鍵區的六顆分段按鈕改為**三個 toggle**，三態（全開／全關／混合）由 `aria-checked` 承載；計數改排在標籤下方
- 移除一鍵區的常駐漏遮警示條，該訊息改由逐列的「未偵測」標示與預覽區的警示條承擔
- 模型狀態列改為**不佔版面流的浮動列**，就緒後自動收起，失敗則常駐
- **整個側欄**（預覽區 ＋ 商品說明）在寬版面下固定跟隨捲動，且兩者不互相遮蓋
- 左欄從一張大白卡拆成**四張卡**（選擇照片／匯入／輸出設定／照片清單）；匯入到的商品名稱歸輸出設定、清空歸清單
- 商品說明的標題改為**商品名稱本身**，並讓名稱、段落標題、內文三個層級用不同手段區分
- 預覽區的提示拆成三個層級：中性讀數、警示條、以及照片本身的「不下載」呈現
- 縮放列移入照片右下角，檔名成為照片的圖說
- 移除兩段常駐的編輯模式說明，內容併入頁尾的使用說明
- 清單前導欄改為「核取方塊 → 把手 → 序號」，把手與核取方塊同尺寸，序號置中
- 開關晶片改為純文字（移除圖示）
- 匯入與「用這個命名」兩顆按鈕共用同一套外觀；匯入的商品名稱補上標題
- 匯入進度改成長在**觸發它的按鈕上**（spinner ＋ 底部進度線），零版面位移
- 修掉超長輸出命名把左欄撐爆的版面問題（兩個 grid 軌道的最小尺寸都要釘回 0）
- 清空時一併清掉 JAN 欄位

## Impact

- Affected specs: `unified-studio`
- Affected code: `studio.html`、`tools/verify/studio.mjs`、`README.md`
- 三條逐位元不變量（四格輸出矩陣）不受影響：`processed()`、`compose()`、`plan()`、`item.cache` 一律未動
- 與尚未 archive 的 `add-download-selection` 有重疊：該 delta 中描述「分段點亮」的情境已就地改寫為 toggle 的說法
